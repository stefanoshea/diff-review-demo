# diff-review demo

A tiny session and billing service. Sessions last 30 minutes and refresh on activity, for up to 12 hours. It exists to show the [diff-review](https://github.com/stefanoshea/diff-review) Claude Code mod on a real pull request.

Try it in Claude Code with the mod installed:

```
/diff-review stefanoshea/diff-review-demo#1
```
